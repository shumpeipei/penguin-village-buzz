ペンギン村(buzz版)とは？

利害関係のない場所で、適度な距離感を保ちながら雑談ができる有志のコミュニティです。日常のつぶやきや趣味の話など、気が向いたときにふらっと立ち寄れる場を目指しています。

  • 👀
    見るだけ（ROM専）大歓迎
    会話に混ざらず、ただ眺めているだけでも全く問題ありません。挨拶も不要です。
  • 🚪
    出入り自由・適度な距離感
    来たいときに来て、離れたいときは静かに離れられる、縛りのない空気感を大切にしています。
  • ☕
    タイムライン疲れのない雑談
    アルゴリズムに追われるSNSから離れて、マイペースにゆるい会話を楽しめます。

参加方法

参加は18歳以上です。スマホでもPCでも、buzzアプリのインストールと BuilderLab（新しいタブで開きます） のアカウント登録が必要です。ブラウザだけでは入れません。

ご利用前にご確認ください buzz は Developer Preview 版のため、容量などの制限があり、仕様が変わることがあります。

まずはスマホの手順です。PCの方は、下の PCから参加する場合 を開いてください。

  1. buzzアプリをインストールする
    ストアからアプリを入れてください。
    App Store (iOS)（新しいタブで開きます） Google Play (Android)（新しいタブで開きます）
  2. アカウントを作成してログインする
    アプリを開き、アカウントの作成またはログインを選んでください（英語表示では Create account / Sign in）。メールアドレスで BuilderLab に登録してログインします。実名や電話番号は不要です。
  3. このページに戻り、参加ボタンを押す
    アプリを開いただけでは入室できません。下のボタンから招待を開き、アプリの案内に従って入室してください。
※同じ BuilderLab アカウントでログインすれば、スマホとPCで同じ身分のまま参加できます。
※LINEなどのアプリ内ブラウザでは、参加ボタンからbuzzアプリへ移れないことがあります。メニューの「Safariで開く」または「デフォルトのブラウザで開く」から開き直してから押してください。
ペンギン村(buzz)の参加リンクを開く（新しいタブで開きます）

アプリのインストール中にページを閉じても、コピーしたリンクをメモや自分宛のメッセージに貼っておけば、すぐ戻れます。

PCから参加する場合

PCでもブラウザだけでは入れません。デスクトップアプリと BuilderLab のアカウントが必要です。参加は18歳以上です。

  1. PC用のbuzzアプリをインストールする
    macOS / Windows / Linux 向けです。公式のダウンロードから入手してください。
    デスクトップ版をダウンロード（新しいタブで開きます）
  2. BuilderLabのアカウントでログインする
    アプリでアカウントの作成またはログインを選んでください（英語表示では Create account / Sign in）。スマホで作ったアカウントと同じもので入れます。
  3. 参加リンクをアプリで開く
    PCのブラウザでこのページの「ペンギン村(buzz)の参加リンクを開く」ボタン（上の手順の下にあります）を押し、アプリの案内に従って入室してください。アプリを起動しただけでは入れません。

村の掟（ガイドライン）

みんなが居心地よく過ごすためのシンプルなルールです。

  • 他者への誹謗中傷、攻撃的な発言は行わない
  • 個人の特定につながる情報の投稿は避ける
  • 過度な干渉はせず、お互いの距離感を尊重する
  • 参加は18歳以上の方に限ります
  • ルールに反する投稿は、運営の判断で削除や退室のお願いをすることがあります
  • 去る者を追わず、来る者を拒まず

よくある質問

会話をせず、見るだけ（ROM）でも参加できますか？
もちろん大歓迎です。挨拶も不要ですので、気軽に雰囲気を覗いてみてください。
本家ペンギン村（有料版）に入っていなくても参加できますか？
はい、どなたでも自由にご参加いただけます。本家未参加の方もお気軽にどうぞ。
利用料金はかかりますか？
当コミュニティの利用は無料です（buzzプラットフォーム自体の仕様変更等の場合を除く）。
ブラウザだけでも参加できますか？
参加できません。スマホでもPCでもbuzzアプリのインストールが必要です。あわせて BuilderLab のアカウント登録も必要です。
実名や電話番号の登録は必要ですか？
実名や電話番号は不要です。BuilderLab のアカウント登録（メールアドレス）は必要です。村の中ではニックネームで参加できます。
参加リンクが開けない・入室できないときは？
招待リンクは定期的に更新されます。古いページを開いている場合は再読み込みして最新のリンクを押してください。LINEなどのアプリ内ブラウザの場合は、Safari / Chrome で開き直してください。それでも解決しない場合は、GitHub Issues（新しいタブで開きます） でお知らせください。

まずは気軽に覗いてみませんか？

アプリと BuilderLab アカウントの準備ができてから、参加リンクを開いてください。
