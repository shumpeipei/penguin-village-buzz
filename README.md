# 非公式 ペンギン村 (buzz版) Webサイト

buzz.xyz 上で展開する、有志による非公式コミュニティの紹介・参加案内LPです。

参加は18歳以上です。当コミュニティを利用する料金は無料です（現時点。Buzz は Developer Preview で、容量などの制限があります）。

## 公開URL
- https://shumpeipei.github.io/penguin-village-buzz/

## 技術スタック
- HTML5 / CSS3 (ビルド不要の静的ホスティング)
- GitHub Pages

## デプロイ手順
1. このリポジトリをクローンまたはフォークします。
2. GitHubのリポジトリ設定（Settings）を開きます。
3. `Pages` メニューを選択します。
4. `Build and deployment` の Source を `Deploy from a branch` に設定します。
5. Branch を `main`、フォルダを `/ (root)` に設定して `Save` をクリックします。
6. 数分後に指定URLにて公開が完了します。
